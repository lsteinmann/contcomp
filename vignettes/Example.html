shapare - shape/compare - an addition to shapAAR

Lisa Steinmann

2018-04-09

This package is designed to compare shapes of vessel or possibly other objects. It depends on the contour vectors produced by ISAAKiels shapAAR-package (hence the name). The contour vectors should ideally be in the format as illustrated by the files in ./inst/doc/. The contours in those files were produced with shapAAR (and a modification of the bulkIMGloop function that can be found there as a branch). I chose a larger image size and scaled the contours to 500px length, not 100px as proposed by ISAAKiel, to get a more detailed result. (Additionally I only used the left side of the drawings, so I could ignore the handles.) Thumbs (./inst/img/) and txt-files (./inst/doc/) are included in this package, but not the original images, since I am unsure about the copyright. The sources are:

  • Eilmann: R. Eilmann, Frühe griechische Keramik im samischen Heraion, AM 58, 1933, 47–145
  • Furtw: A. Furtwängler, Heraion von Samos: Grabungen im Südtemenos 1977, I: Schicht- und Baubefund, Keramik, AM 95, 1980, 149–224
  • Kopcke: G. Kopcke, Heraion von Samos: Die Kampagnen 1961/1965 im Südtemenos, AM 83, 1968, 250–314

One of the purposes of this package was to automatically identify the ‘areas’ of a vessel, e.g. the rim, in order to later (automatically?) compare them with fragments. The find_shinoto_index()-function provides a data frame with such information, but currently it’s only a start.

Am Beispiel einer prähistorischen Irdenware aus Südjapan, see for example p. 250). Implementation is not yet done.

model_df <- data.frame(x=c(1:1000))
for (col in 1:ncol(shapaardata_df)) {

  model_df[,col] <- wip$modelcontour
  rm(wip)
}

Three versions of a manual distance matrix (sadly not an object of class ‘dist’) can be produced (this may take some time):

#curve_dist <- get_curve_dist(model_df = model_df, type = "sd")
frechet_dist <- get_frechet_dist(model_df = model_df)
#procrustes_dist <- get_procrustes_dist(model_df = model_df)

curve_dist() was my own attempt at finding a way to quantify the (dis)similarity of two curves and uses either

  • the standard deviation of the ‘difference curve’ (‘difference curve’ = absolute values resulting from the subtraction of contour1 and contour2)
  • the sum of all values of said ‘difference curve’

SD seems to work better, but in the end both don’t work as well as the Frechet-Distance (in this case from the package SimilarityMeasures). I thought that the Procrustes-Distance might be worth a try, but am not happy with the results.

I will only illustrate the results of the Frechet-Distance measure. There are two ways of visualizing the results, one being in a coordinate system with coordinated obtained via principal coordinates analysis:

frechet_coords <- as.data.frame(cmdscale(frechet_dist))
frechet_coords$label <- rownames(frechet_coords)
colnames(frechet_coords) <-  c("x", "y", "label")
frechet_coords <- merge(frechet_coords, attrib_df)
library(ggimage)
ggplot(data = frechet_coords, aes(x = x, y = y)) +
  geom_image(aes(image = thumb)) +
  geom_point(aes(colour = type)) +
  coord_fixed()

This seems to seperate different types rather nicely. Maybe another dimension could be added to display the objects in a 3D-coordinate system, to differentiate a bit better.

The results might as well be displayed in a heatmap:

palette <- colorRampPalette(c('chartreuse4','white'))(256)

Or with a cluster dendrogram:

library(ggdendro)
library(cluster)
clust <- diana(frechet_dist, metric = "euclidean")
dendr <- dendro_data(clust)
dendr$labels <- merge(dendr$labels, attrib_df)

ggplot() +
    geom_segment(data=segment(dendr), aes(x = x,
                                          y = y,
                                          xend = xend,
                                          yend = yend)) +
    geom_text(data=label(dendr), aes(x = x,
                                     y = y-3000,
                                     label = label,
                                     colour = type),
              size=3,
              hjust = 0) +
    geom_image(data=label(dendr), aes(x, y-3, image = thumb), size = .015) +
    coord_flip() +
